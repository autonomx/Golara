# Golara

Golara is a modern editable flower and luxury gift storefront. The project is intentionally not Joomla-based: it will provide Joomla-like site editing through a custom admin/CMS layer while keeping the public storefront fast, clean, and easy to extend.

## Phase 1 scope

- Next.js App Router storefront scaffold
- RTL-ready visual system
- Seeded flower/category/product data
- Homepage, catalog, category, and product detail pages
- Admin dashboard placeholder describing the editable CMS workflow
- Prisma schema draft for the future database-backed CMS

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Planned stack

- Next.js
- TypeScript
- Tailwind CSS
- Prisma
- PostgreSQL in production
- Local seeded data first, database-backed CMS next
