# Phase 5.20-5.22 visible paths

This bundle adds visible path navigation for category and product pages.

## Added behavior

- New `PathTrail` component.
- Category pages show `Home / Category` path navigation.
- Product pages show `Home / Category / Product` path navigation.
- Machine-readable JSON-LD breadcrumb data remains unchanged.

## Current scope

This is a small user-facing navigation improvement for product/category pages only.

## Deferred

- Site-wide path navigation.
- Locale-specific labels.
- RTL path navigation QA.
- More advanced accessibility/styling pass.
