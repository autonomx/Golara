# Production Security Release Exceptions

Use this register to track release items that need an owner decision before launch. Keep entries short and link to approved evidence instead of copying detailed records.

| Owner |  |
| Approver |  |
| Review date |  |
| Follow-up required |  |
| Evidence links |  |
| Final decision | Proceed / block / defer |

## Review expectations

- Every open exception needs an owner and review date.
- A blocked required check should stay open until the provider status clears or release ownership records a decision.
- Deferred work should name the condition that brings it back into scope.
- Accepted items should be reviewed before the next production release.
