# Phase 4.46-4.48 public order view

This bundle improves the customer-facing order status page.

## Added foundation

- Friendlier public labels for internal order statuses.
- Friendlier public labels for fulfillment statuses.
- Delivery date/window display when available.
- Public privacy boundary remains unchanged.

## Privacy rule

The public order page still does not expose address, phone, courier details, customer notes, or staff-only notes.

## Deferred

- Customer-facing notification preferences.
- Delivery provider tracking links.
- Full customer account order history.
