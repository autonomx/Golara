# Phase 5.50-5.52 card focus

This bundle improves keyboard focus visibility on storefront cards.

## Added behavior

- Category cards now include a visible `focus-visible` ring.
- Product cards now include a visible `focus-visible` ring.
- Both card links keep existing hover styling.
- No layout or data behavior changes.

## Why

Storefront card links are large interactive targets. Clear keyboard focus treatment makes category and product browsing easier to validate and use.
