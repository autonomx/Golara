# Golara missing product image prompts

Use these prompts with ChatGPT image generation for the seeded products that still need real product imagery.

## Output requirements for every image

- Format: JPG
- Exact size: 1600 x 2000 px
- Aspect ratio: 4:5 portrait
- Save each generated file in: `public/seed-images/photo-real/`
- Use the exact filename shown for each prompt.
- No people, no hands, no visible text, no watermark, no logo, no signage, no brand labels.
- Product should be centered with enough margin for product cards.
- Style should match a premium luxury floral ecommerce catalog: photo-realistic, warm studio light, soft shadows, shallow depth of field, elegant cream/beige backdrop.
